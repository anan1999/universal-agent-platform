# Orbital courier — evolving 3D animation task

Create a self-contained Python animation in `animation.py`, using 3D scene
coordinates and a perspective projection rendered into GIF frames with Pillow.
The animation depicts a small courier satellite moving around a planet. Use
procedural primitive geometry; no downloaded assets, Blender installation, or
network are required. The user will refine this one scene over multiple turns.
Keep the animation loop and prior features working. A final GIF must be
viewable independently of the source code.
