# Product brief

Rank problems by `interviews * severity * strategic_fit`. Select the highest-ranked problem.
Rank features for that problem by `impact / effort`, highest first. The launch roadmap must contain
exactly the two features belonging to the selected problem, in rank order. Write `deliverable.json`
with `selected_problem`, `roadmap`, `success_metric`, and `risks`. Use success metric
`weekly_task_completion_rate`; include at least two non-empty risks.
