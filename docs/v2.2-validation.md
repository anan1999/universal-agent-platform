# V2.2 validation record

Validated on 2026-09-10 on Windows with Python 3.11.2. All automated execution used the
deterministic Mock provider and consumed zero external AI quota.

## Automated validation

- `pytest -q`: **140 passed**, with one upstream Starlette/TestClient deprecation warning.
- `python -m compileall -q src scripts`: passed.
- Domain matrix passed for software, AI engineering, UI/UX, product, research, writing,
  DevOps, unknown-domain, trivial, and read-only goals.
- V2.2 strategy tests cover tool-only, single Agent, single Agent with tools, parallel Agents,
  dependency DAG, human approval, and artifact-only execution.
- Skill tests cover capability equivalence, deterministic ranking, progressive loading,
  dependency cycles, temporary synthesis, unsafe-content blocking, exact run/version records,
  promotion candidates, and authoritative artifact evaluation.

## Context benchmark

`python scripts/skill_context_benchmark.py --json` measured 20,101 eager characters versus
3,174 progressively loaded characters: **84.21% less context**, estimated as 5,026 versus 794
tokens, with zero AI invocations. See `docs/v2.2-skill-benchmark.md` for the method and limits.

## Distribution validation

Standard isolated `python -m build` produced:

- `universal_agent_platform-2.2.0.tar.gz`
- `universal_agent_platform-2.2.0-py3-none-any.whl`

The wheel was installed into a clean virtual environment and invoked from outside the source
checkout. `agentctl --version` returned `2.2.0`; setup completed with schema v6, ten profiles,
eight models, and two ready providers. The packaged `w8a8-validation@1.0.0` Skill validated and
ranked first for `w8a8 validation`.

The installed import resolved from the virtual environment's `site-packages`, not the repository.
The packaged Skill resource existed. No `resources/dashboard` directory existed, and CLI help did
not contain a `dashboard` command.

## Dashboard removal

Per product direction, V2.2 has no bundled Dashboard. Its HTML/CSS/JavaScript, static FastAPI
mounts, `agentctl dashboard`, Uvicorn runtime dependency, package-data entries, setup/doctor
claims, and current onboarding references were removed. Read-only JSON APIs and CLI
explain/replay/history remain available for integrations and audits.

## Real providers

No real provider invocation was performed for this V2.2 validation, so it consumed no subscription
quota. Provider behavior is covered by offline tests; V2.1's bounded Codex validation remains the
latest real-provider regression evidence.
