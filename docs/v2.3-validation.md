in place. No Dashboard was reintroduced.

- `universal_agent_platform-2.3.0-py3-none-any.whl`

arbitrary empty project, `agentctl --version` returned `2.3.0`; setup created schema v7; init,
`warm-start`, and packaged profile loading succeeded. The Project Intelligence package and all
runtime resources were loaded from the installed wheel.
