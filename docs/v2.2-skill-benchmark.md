# V2.2 Skill intelligence benchmark

This benchmark is deterministic and offline. It consumes zero AI invocations and is intended to
measure context packaging, not model intelligence.

Run:

```bash
python scripts/skill_context_benchmark.py --json
```

The fixture contains one instruction file, five optional references, and three examples. The
eager baseline counts the manifest plus every Markdown asset. The progressive path counts the
same manifest plus `SKILL.md` and one explicitly selected reference.

Release result:

| Measure | Eager | Progressive |
|---|---:|---:|
| Characters | 20,101 | 3,174 |
| Estimated tokens (four characters/token) | 5,026 | 794 |

That is 16,927 fewer characters, an **84.21% reduction**, with **0 AI invocations**. Token values
are explicitly estimates; the character counts are measured from the generated fixture.

For structured-output effectiveness, the offline acceptance tests use the same declared-artifact
evaluator for both cases: an unstructured self-report without required evidence fails, while a
structured artifact containing the required file/section passes. This is a deterministic contract
test, not a claim that one prompt universally improves model quality. A real-provider comparison
is intentionally opt-in because normal tests and this benchmark must consume no subscription
quota.
