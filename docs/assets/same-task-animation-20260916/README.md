# Orbital Courier benchmark previews

`baseline.gif` and `uap.gif` are final 640×480, 12-frame rendered previews
from two independent 10-turn Codex tasks using the same scripted user requests.
They are examples for human visual inspection, **not** proof of equivalent
artistic quality. The deterministic benchmark and corrected quality results
are described in `../../same-task-programming-animation-results-20260916.md`.
